# Suite 2 source evidence for DeathStarBench, Train-Ticket and Online Boutique

Candidates and consumer sets come from the pinned source calls, signatures, Thrift/proto declarations and Spring route annotations. Graph node IDs were matched from the declaration file, symbol and line. Graph edges were checked afterwards for coverage. No retrieval or scoring ran.

The graphs were rebuilt in memory from `egpot-bench-builder-v1` (`94aae7b8aef08ac2beddcbc7fc37a7e2b2cc69ce`) using the tagged Python sources loaded from Git blobs. The audit guard blocked writes, subprocesses and sockets during builds and coverage checks. Protobuf used its source-parser fallback. DSB used each app’s recorded service roots and one Thrift-only root. Train-Ticket used its recorded 47-service build configuration with the nonproduction filter enabled. Boutique used the 12-root DEV workspace layout.
