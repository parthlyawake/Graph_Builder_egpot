# DataHub Suite 2 structural reachability

Rebuilt DataHub `c2a82c97f0faf73c266d6525aead90557615147f` in memory with the v3 production roots and filters under the write, network and subprocess audit guard. The frozen builder check passed for `egpot-bench-builder-v3` (`ea3f50e25f22e141495569207a8b16cbbd79e319`). The rebuilt graph had 314,219 nodes and 1,032,832 edges. No retrieval or scoring was run.

All-edges reachability follows both incidences of every graph edge. LEGACY and Policy D follow the same incidences with the RPC choke rule enabled. Policy D leaves all relation types eligible and changes only contract-match scoring, which this check does not use. Plain BFS counts the start as discovery position 1, visits each node once, and uses the sorted neighbor order in the graph view. Budgets are node counts, not hop limits.
